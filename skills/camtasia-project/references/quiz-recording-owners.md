# Frozen and stitched quiz owners

Use the [quiz helper contract](helper.md#quiz-json-editing) for native XML
authoring, inspection, retiming, exact-payload owner transfer and removal.
Its compiler owns supported owners and clock conversion. These observations
cover existing frozen/stitched recordings; creating those media arrangements
retains the [native ownership contract](animations.md#frozen-and-stitched-owners).

## Native pin and unpin

Camtasia Mac 2026.2.4 / format 10 pins a timeline quiz at nine seconds onto the
stitched parent's quiz parameter at source second nine. Unpinning restores the
same point on the timeline. Neither operation changes the XML bytes or the
quiz, question and answer identities. Whole-document helper replay matches
both native captures apart from the thumbnail and UI command counter.

After native unstitching, the standalone held recording begins at eight seconds
and retains source frame `5621280000` with `mediaDuration: 1`. Native pinning
instead places that quiz at local second one. Unpinning restores timeline second
nine with the exact XML. The selected source frame does not set the quiz origin.

A retimed native comparison uses inverse-speed scalar `"1/2"`. The held point
at local second one maps to global 8.5 seconds. A stitched parent starting at
ten seconds, trimmed to source second two, maps its source second nine to
global 13.5 seconds. Native pin/unpin in both directions preserves those global
positions and unchanged XML. Independent fixtures retain these exact ticks,
cursor payload, child clocks, source selection and independent audio.

Select the stitched parent. Its hidden moving/held children are not independent
quiz owners. Linked variants require a separate native ownership contract;
their aliases remain refused. The shared hotspot and other helper selectors
retain their existing scopes.

## Exported owner and timing controls

A helper-authored 36-second sequence contains authored, unpinned and explicitly
retimed quizzes for both owner forms. Unpinned points live on the timeline;
the other four retain their media owners. Two additional points are authored
and removed before export. Native XMP contains only the six retained quiz sets,
at 1, 6.5, 13, 21, 27 and 33.25 seconds. Their Unicode question text, one correct
choice and response feedback survive export. Both packages pass six actual
correct responses, matching feedback text, 100% results for every quiz and
continued playback. Twelve inspected frames retain the synthetic page and
recorded pointer. The player pauses before the serialized quiz points; its
rounded prompt labels are separate from the exact XMP millisecond times.

The first native save remaps clip IDs, collapses static held descriptors and
adds the thumbnail. It preserves all six XML strings and point times, source-bin
definitions, cursor payload, effects and other fields. All three bundled source
hashes remain unchanged. A second fresh-process save is byte-identical. Both
native web packages have identical complete decoded video and stereo audio;
their movies are 36-second 852×480 H.264 with 44.1 kHz AAC. The candidate and both
saves pass the pinned raw schema and exact-build compatibility profile.
